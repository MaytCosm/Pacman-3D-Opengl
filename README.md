Juego 3D estilo Pac-Man desarrollado en C++ con OpenGL

Cuenta con:
- Laberinto 3D con colisiones.
- Fantasmas: persecución y huida.
- Sistema de vidas y créditos.
- Dos modos de cámara: cenital e isométrica.

 Controles
- W/A/S/D: Mover a Pac-Man.
- I: Cambiar vista de cámara.
- Flechas Izq/Der: Rotar cámara.
